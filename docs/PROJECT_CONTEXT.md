- yuvToImageC的C实现与Emscripten产物已核对；写为通过emsdk工具链编译C到WASM，不称emsdk是运行时模块。
- 三技术点改为单层直接展示，每条问题/处理/结果+一个折叠细节，取消套用Universe的多级模块与内部编号。资产压缩目的是减少加载和渲染成本，环境光/预加载/告警回收合并为辅助处理，不再各自大篇展开。
