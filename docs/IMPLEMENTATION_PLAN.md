状态：用户已确认方案 A，并于 2026-10-26 授权第一版 MVP 实现。

## 依据与边界

- 以用户本轮提供的 Project Context 及 `docs/references/homepage-reference.png` 为依据。已将已确认上下文整理到 `docs/PROJECT_CONTEXT.md`。
- 保留 Editorial + Interactive Graphic Design + Generative Art + Minimal 3D 方向。
- 暖白背景、灰黑细线、留白、严格对齐；主视觉始终为抽象参数化曲线。
- MVP 包含首页、Idle / Hover、进入转场、静态对话原型；不接 LLM API。

## 参考图分析

- 中央偏下的闭合椭圆曲线簇，形成横向外轮廓、倾斜中央留空、两侧疏密变化和局部交汇。
- 空间感主要来自曲线朝向、重叠和轮廓变化；无需实体表面、复杂灯光或真实材质。
- 细虚线坐标与参考椭圆是次级图形，明度低于主体。
- 顶部双端元信息和横向分隔线；左上两行标题；底部左侧身份、右侧入口；主体周围保留充分留白。

## 候选几何方案

| 方案 | 实现难度 | 动态形变 | 参考还原潜力 | 风险 |
| --- | --- | --- | --- | --- |
| A：共享中心、逐条旋转和倾斜的空间椭圆曲线族 | 低至中 | 高，可独立调轴长、角度和轻微波动 | 高，直接控制中央留空与外轮廓 | 等间隔全周排列容易变成球形或均匀花瓣 |
| B：环面上的斜向闭合曲线族 | 中 | 高，可调环半径、绕行频率和相位 | 中至高，空间结构自然 | 容易出现明显甜甜圈轮廓或过密缠绕 |
| C：周期谐波 / Lissajous 曲线族 | 中至高 | 很高，可连续调振幅与相位 | 中，需较多轮廓约束 | 容易变为复杂线团，破坏留白和安静感 |

MVP 已采用 A。单张参考图无法确定原始三维结构，优先匹配投影视觉。

椭圆基础形式为 p_i(t) = R_i · [a_i cos(t), b_i sin(t), 0]，t 属于 [0, 2π]。
R_i 控制各条曲线的空间姿态；轴长、角度分布与正交相机共同控制轮廓。不使用随机噪声作为主要造型来源。

## 阶段 1：静态几何验证

- 建立最小 Vue 3 + TypeScript + Three.js 页面与正交相机。
- 以约 12–18 条闭合曲线、每条约 128–256 个采样点为调参起点，数量以截图对比结果为准。
- 使用可控屏幕线宽的线条方案，避免原生 WebGL 线宽的跨平台限制；优先 Three.js 自带 addons，不引入额外框架。
- 固定视角验证外轮廓、中央留空、曲线密度、线宽与颜色。
- 验收：静止截图接近参考图结构；不呈现球形、实体管道或具象物体。

## 阶段 2：Editorial 首页

- 用 CSS Grid 建立顶栏、标题、艺术区域和底部信息区。
- 从参考尺寸校准比例，再适配桌面、平板与手机；窄屏采用正常文档流避免重叠。
- 辅助虚线降低对比度，避免遮盖主体。
- 验收：不同视口中标题和曲线不碰撞，文字可读，留白与对齐稳定。

## 阶段 3：Idle / Hover

- 建立 idle / hover / entering / chatting 状态。
- Idle 使用低频、小幅参数变化；Hover 使用指针归一化位置驱动平滑倾斜与有限形变。
- 以独立 DOM 按钮覆盖艺术装置交互区，使中央留空也能点击；支持键盘焦点与触屏点击。
- 显示克制的 AI 入口提示；遵循 prefers-reduced-motion，页面隐藏时暂停动画。
- 验收：指针进入与离开无跳变；静止后平滑归位；长时间运行不漂移。

## 阶段 4：进入与返回转场

- 用 GSAP 编排同一组几何参数，完成曲线展开、缩放和侧移，再呈现对话区域。
- 保持曲线和采样点数量不变以便插值；动画期间防止重复触发。
- 保留淡化的曲线视觉；提供返回首页并恢复初始状态的路径。
- 验收：无闪屏、突变和文字遮挡，重复进入与返回行为一致。

## 阶段 5：静态 AI 对话原型与最终验证

- 提供助手介绍、履历 / 项目 / 技能问题入口、输入区和本地预设回答。
- 明确为演示模式；真实资料未提供时使用清晰标注的占位内容，不编造经历。
- 完成键盘操作、焦点移动、消息滚动与移动端布局。
- 执行类型检查与构建；桌面和手机截图复核，验证减弱动态模式与重复转场。
- 性能以目标设备实测为准，优先降低像素比和采样密度，不牺牲主要轮廓。

### 02 坐标系对齐：将 VPS 展项映射到 AR 会话

- T：建立会话与地图之间的变换，使地图锚点与实时相机位姿可在一致的数值约定中参与渲染和空间判断。

- T：把相机位姿转成明确的展项进入/离开事件，并衔接对应展项的 AI 请求。

- 对同一基底切换使用 `p'=Bp`、`R'=BRB^-1`。两套同手性的完整正交基底映射行列式应为 +1，一轴取反为 -1；因此不能由项目接口都左手，推断 Fy 就是完整跨系统映射。必须区分地图世界轴、相机局部轴和中间表达。
- 若 `P'=C P` 为世界基底变换，且 Anchor 也表达在相同校正帧，则恢复原会话 `A=C^-1 A'`；一致的固定左乘可从相机驱动中移出并合入 Anchor 路径。该推导不是对运行代码的真机验证。
